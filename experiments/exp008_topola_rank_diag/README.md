# exp008 topola_rank_diag

## 问题

exp005–007 把 TopoLa 放在桥接切片的跨模态配对上(稠密、一对一),没有超过 Vanilla。
在把 TopoLa / BPR+ 改用到其他位置(例如以 MNN 边为正关系的链接预测)之前,先回答一个更基础的问题:
**在不改训练的前提下,TopoLa 分数是否比余弦更能把真实对应关系排在前面?**
同时直接测量 exp007 README 中对 iLISI 下降的机制推测(白化压低主方向,模态间隙因此不受惩罚)。

本实验是诊断,不改训练目标。三部分:

1. **跨模态对应排序(训练后嵌入)**:Lymph-S1-S2-S2、Tonsil-S1-S2-S2、Simulations 的 slice2(只有 RNA)
   与 slice3(只有 ADT)是同一批 spot,真实配对已知。用同一组嵌入,比较余弦与 TopoLa 分数(不同参考集合、不同 λ)
   对真实配对的排序质量。
2. **跨切片 MNN 关系质量(输入特征)**:同一模态内 S1 ↔ 非桥接切片,在预处理后的输入特征上,
   比较余弦与 TopoLa 的互近邻(mutual kNN)对的区域标签一致率。这对应「用 MNN 边做 BPR+ 正关系」时正关系本身的质量。
3. **嵌入几何(训练后嵌入)**:比较 dot 与 topola_cal 训练出的嵌入的有效秩、slice2–slice3 质心间距、
   桥接切片跨模态残差在各主成分方向上的分布。

## 假设

- H_rank:存在一种 TopoLa 设置(参考集合 × λ),在 dot 训练的嵌入上比余弦更好地排出真实跨模态配对。
- H_mnn:在输入特征上,TopoLa 的互近邻对比余弦的互近邻对有更高的标签一致率。
- H_geo:与 dot 相比,topola_cal 训练出的嵌入有效秩更高,slice2–slice3 质心间距更大,
  桥接残差相对于该方向方差的比例在前 3 个主成分上更大(即主方向上的跨模态不对齐更多)。

## 唯一改动的因素

评估时的打分函数:余弦 vs TopoLa。训练只有两个已有 arm,均不改动:

- `dot`:Vanilla,即 exp005 的 dot。
- `topola_cal`:exp005 的 `D_λ/mean(diag D_λ)`,λ=10。

两个 arm 都用 exp005 的 `StableCL_loss`。预处理、构图、WLGCN、`w_g=0.8`、`lr=0.01`、100 轮、
`intra_knns=10`、`inter_knn_base=10`、T(Simulations 0.1,其余 0.01)全部沿用 exp005。
S1-S2-S2 数据集首次加入,沿用 exp005 对真实数据的预处理(`n_hvg=5000`;reproduce 原 notebook 用 10000,
这里为与 exp005 的 S1-S2-S3 保持一致而不采用)。

TopoLa 打分统一写成 `s(q,c) = e_q (RᵀR + λI)⁻¹ e_cᵀ`,R 为参考集合。λ 采用与尺度无关的参数化
`λ = α · tr(RᵀR)/d`(即 α 乘以 RᵀR 的平均特征值),α ∈ {1e-4, 0.1, 0.3, 1, 3, 10, 100}。
α=1e-4 接近投影极限,α=100 接近余弦(自检)。另加一个与训练核相同的设置(参考=桥接,λ=10 绝对值)。

参考集合:
- `pair`:查询与候选(slice2 ∪ slice3),对应论文接口 E=[C;Z]。
- `bridge`:桥接切片两个模态的嵌入,与训练时的核相同。
- `all`:所有切片、所有模态的嵌入。

打分变体:`topo`(上式,即 D_λ 的对应元素)与 `wcos`(白化后再逐行 L2 归一的余弦,用来区分「方向重新加权」与「范数/枢纽效应」)。

## 基线

exp005 的 dot(Vanilla)与 topola_cal 的配置。排序与 MNN 部分的基线是同一组嵌入/特征上的余弦。
自检:S1-S2-S3 两个数据集与 Simulations 的 iLISI 应与 exp005 在噪声内一致(exp005 dot 的 seed 间 std 0.004–0.014;
MNN 用 annoy 近似检索,不保证逐位复现)。

## 设计

- 训练:5 数据集(Simulations、Lymph-S1-S2-S3、Tonsil-S1-S2-S3、Lymph-S1-S2-S2、Tonsil-S1-S2-S2)
  × 2 arm × 5 seed(1234、2024、2025、2026、2027)= 50 次。每次保存各切片各模态的嵌入与 MNN 对(`results/runs/`,不入库),
  并计算 iLISI。两张卡并行。
- 排序指标(第 1 部分,3 个有真实配对的数据集):FOSCTTM(与 reproduce 实现一致,严格大于计数,越小越好)、
  MRR、Hit@1、Hit@10,均为两个方向平均;互近邻(k=10)对中真实配对的比例与区域标签一致率(Simulations 两个模态的 gt 不同,不算标签一致率)。
- MNN 质量(第 2 部分,5 个数据集 × 2 模态,输入特征逐行 L2 归一):互近邻 k=10 的对数与标签一致率,
  并给出随机配对的期望一致率;同时报告 SpaMosaic 实际构图得到的 MNN 对(annoy,seed 1234 的 dot run)的一致率。
- 几何(第 3 部分,全部 50 个 run):合并嵌入的有效秩(协方差特征值熵的指数)、slice2–slice3 质心间距及其在前 3 个主成分上的能量占比、
  桥接残差 r = e_rna − e_adt 的均方范数、均值范数,以及相对不对齐 ρ_k = E[(r·v_k)²]/λ_k 在前 3 个与其余主成分上的均值。

## 判定标准(事先给定)

- H_rank 成立:在 dot 嵌入上,存在一个**对三个数据集相同**的设置(参考 × 变体 × α),
  使 FOSCTTM 相对余弦下降 ≥10%,且每个数据集 5 个 seed 中至少 4 个下降。
  「无优势」:没有任何设置能在至少 2 个数据集上使 FOSCTTM 相对下降 ≥3%。介于两者之间记为「弱」。
  只有 `pair` 参考成立时单独注明(它在评估时使用了候选集合本身,属于转导设置)。
  α=100 与余弦的 FOSCTTM 差应 <1%(自检)。
- H_mnn 成立:Lymph 与 Tonsil(S1-S2-S3)的 4 个「数据集×模态」组合中至少 3 个,存在某个 α
  使 TopoLa 互近邻标签一致率 ≥ 余弦 + 0.02,且对数在余弦的 ±30% 内。
- H_geo 各子项成立:在 Lymph-S1-S2-S3 与 Tonsil-S1-S2-S3 上,该子项 topola_cal 相对 dot 的方向符合假设,
  且每个数据集 5 个 seed 中至少 4 个同向。
- 日志中出现 `Traceback`/`Nonfinite` 的 run 不计入并重跑(只修 bug)。
