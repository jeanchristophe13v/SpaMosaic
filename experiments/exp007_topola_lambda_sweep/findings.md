## 按 README 判定标准

- 自检(λ=1e5 vs dot):通过。iLISI 配对差 Simulations +0.003 / Lymph +0.001 / Tonsil +0.000;ARI 配对差 +0.005 / −0.016 / −0.000(均在容差内)。
- 「H_3 成立」(Lymph 与 Tonsil 的 iLISI 从 λ=10 到 1e5 单调不降,允许 −0.01 波动):不成立。
  Lymph 为 0.6246 → 0.6858 → 0.7810 → 0.7331 → 0.7279,Tonsil 为 0.7162 → 0.8165 → 0.8240 → 0.8031 → 0.8011;
  λ=1000→1e4 的回落分别为 −0.048 与 −0.021,超出容差。λ=1e5 的 iLISI 与 dot 差 ≥ −0.02 这一条满足。

  λ=1000 是最接近的:Lymph iLISI +0.055(5/0)、Tonsil iLISI +0.023(5/0),Simulations ARI +0.019(5/0),差 0.001 未达 +0.02;

## 分析

- iLISI 与 λ 强相关。λ=1 与 10 时(远小于真实数据的 `eig_min`≈60)iLISI 最低(Lymph 0.606/0.625,Tonsil 0.671/0.716);
  λ 增大到 100–1000 时回到或超过 dot;λ ≥ 1e4 时与 dot 一致(自检通过)。
  即 exp005 中 iLISI 的下降出现在 λ 小于或接近 `EᵀE` 最小特征值的区间,在 λ 接近 `eig_max` 的区间消失。
- λ=1000(接近真实数据的 `eig_max`)时 Lymph 与 Tonsil 的 iLISI 均高于 dot(5/5 个 seed 为正),但 Lymph 的 F1(−0.023,0/5)和 ARI(−0.024,1/5)低于 dot。
- Simulations 的 ARI 提升随 λ 增大单调减小:+0.030(λ=1)、+0.035(10)、+0.037(100)、+0.019(1000)、+0.002(1e4)、+0.005(1e5);
  λ=1e4 起与 dot 无差别。
- Tonsil 的 ARI 提升只出现在 λ=10(+0.049,5/0)。相邻的 λ=1 为 −0.028(1/4),λ=100 为 −0.005(2/3);各 λ 的 seed 间 std 为 0.022–0.054。
  Tonsil 上 ARI 随 λ 的变化不单调。
- Lymph 的 ARI 在 λ=1–1000 均低于 dot(−0.024 至 −0.051),在 λ=1e4 与 dot 持平(+0.001)。
- 本实验只改变 λ;未对 iLISI 在 λ≈100–1000 附近的回升机制(白化强度、有效秩、嵌入各向异性)作直接测量,以上均为观测关系。
