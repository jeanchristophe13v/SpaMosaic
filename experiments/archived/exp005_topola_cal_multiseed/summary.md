# exp005：换成 TopoLa，有没有收益？

这次保留 SpaMosaic 原来的对比损失，把余弦相似度换成经过幅度校准的 TopoLa。固定核参数 **λ=10**，对比学习温度 **T 保持原值**（模拟数据 0.1，Lymph、Tonsil 0.01）。每个设置跑了 3 个数据集、5 个随机种子。

这里的“幅度校准”，就是把 TopoLa 分数除以核矩阵的对角均值，让分数幅度更便于与余弦比较。λ 负责核的计算，T 负责对比学习温度，两者没有混用。

结果：

- 模拟数据的聚类更准，ARI 从 **0.881 提升到 0.916**；Tonsil 从 **0.121 提升到 0.169**。这两项提升在 5 个随机种子中方向一致。
- Lymph 的聚类变差，ARI 从 **0.228 降到 0.186**。
- 两个真实数据集的批次混合指标 iLISI 都下降了：Lymph 约下降 **0.102**，Tonsil 约下降 **0.085**。
- 三个数据集的空间分区都更连贯（PAS 改善）。

**这次说明：TopoLa 有可以重复的收益，但并非全面提升。它改善了部分聚类结果和空间连贯性，同时也带来了批次混合指标下降等代价。**
